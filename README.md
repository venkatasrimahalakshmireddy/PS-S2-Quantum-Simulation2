# PS-S2 — Real-Time Trotterized Spin Dynamics

**Qiskit Fall Fest 2026 — Phase 1 | Quantum Simulation**

## Problem statement
Simulate real-time evolution \(U(t)=e^{-iHt}\) for a four-spin transverse-field Ising model (TFIM), using first-order Trotterization up to \(t=2.0\). Measure \(\langle Z_0(t)\rangle\), compare against an exact classical matrix-exponential reference, and compare routing/circuit metrics on Processor A (5 physical qubits) and Processor B (9 physical qubits).

Hamiltonian:
\[
H=-J\sum_{i=0}^{2} Z_iZ_{i+1}-g\sum_{i=0}^{3}X_i,\quad J=1.
\]
Initial state: \(|0101\rangle\). The experiment sweeps \(g=0.5,1.0,1.5\) and Trotter steps \(n=1,2,4\).

## What is compared
- Transpiled circuit depth and CX count, plus routing CX overhead relative to an unconstrained compile. Since SWAPs are decomposed into CX gates in the target basis, the project reports a clearly labeled SWAP-equivalent estimate (excess CX / 3), not a false explicit SWAP count.
- Ideal measured \(\langle Z_0\rangle\) against exact \(\langle Z_0\rangle\).
- Noisy measurement under identical synthetic noise rates on A and B.
- Topology diagrams and CSV metrics generated by the experiment.

## Processor design
The coupling graphs are participant-defined, as allowed by the Phase 1 guide:
- **A (5 qubits):** branching tree with edges (0,1), (1,2), (1,3), (3,4).
- **B (9 qubits):** heavy-hex-inspired sparse graph with 12 edges, following the guide's reference edge list.

These are benchmark models, not claims about real hardware. The same synthetic noise rates are applied to both processors so topology/routing differences can be compared.

## Setup
Python 3.10 or 3.11 is recommended.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python run_experiment.py
```

Open `main.ipynb` and run all cells for the notebook workflow. The script writes CSV results and figures into `results/`.

## Repository contents
- `main.ipynb`: end-to-end experiment notebook.
- `run_experiment.py`: command-line runner.
- `src/problem.py`: TFIM Hamiltonian, Trotter circuit, exact reference.
- `src/processors.py`: coupling maps and noise model.
- `src/metrics.py`: circuit metrics and measurement statistics.
- `src/visualization.py`: topology and comparison plots.
- `processors/processor_A.json`, `processors/processor_B.json`: graph/config definitions.
- `report.md`: interpretation template; fill with generated values before submission.

## Reproducibility
Transpilation uses optimization level 1 and seed 42. Simulation uses 4096 shots. Do not manually invent or type benchmark values: run the experiment and submit the generated CSVs/figures.

## Phase 1 scope
Only Processor A and Processor B are required. Processor C and custom Processor D are out of scope for Phase 1.
